# Restaurant landing page (Arabic, RTL)

A single-page sample website for a small oriental restaurant, built with plain HTML, CSS and a little JavaScript. No frameworks.

- Arabic right-to-left layout
- Mobile-first, works down to ~360px wide
- Sections: hero, key facts, menu with category filter, why us, opening hours, WhatsApp order button
- Fast: three small files plus one web font

The restaurant name, menu, prices and numbers are made up for demo purposes. Replace the text, colors and WhatsApp number to fit a real client.

Live demo: https://welcome789000-sys.github.io/restaurant-landing/

نموذج تصميم لعرض الأعمال. صور الأطباق أماكن فاضية والأسعار تجريبية. رقم الواتساب بيتحط في `WHATSAPP_NUMBER` داخل `script.js`.
